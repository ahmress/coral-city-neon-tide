**Coral City: Neon Tide** — an original 2D top-down open-world crime game that runs entirely in the browser. Explore a neon coastal city of three districts (Marina Bay, the Neon Strip, Palmetto Beach) on foot and behind the wheel of three car classes, run a five-job story chain for the city's fixers, and chase a high score built from mission payouts and stunt bonuses — near misses, drifts and top-speed runs — while a five-star wanted system brings patrol cars and roadblocks down on you. A slow dusk-to-night cycle lights up the neon, the pier and the lighthouse. Vanilla JavaScript and Canvas 2D, synthesized WebAudio sound, no build step and no network calls.

Controls: WASD / arrow keys to move and drive, mouse to aim, click to shoot, E to enter or leave a car, Shift to sprint or handbrake-drift, P to pause, M to mute.

## Run it

```sh
node serve.ts
# then open http://localhost:8080 in a desktop browser
```
